## Legend
- **WRITTEN_PERMISSION_REQUIRED:** explicit restriction; myScheme is blocked absent written authorization.
- **DATASET_LICENSE_CHECK:** government open-data policy exists, but permission depends on exact dataset metadata and credentials.

## Mandatory source onboarding checklist

1. Check source/host identity, authenticated sections and whether a public API or licensed download exists.
2. Review the **exact host robots.txt** and current Terms of Use, plus the content/data licence. Archive a dated evidence URL or screenshot.
3. Log permitted endpoint paths, permitted user agent, rate limits, pagination, file licensing and citation/attribution text.
4. Do not collect beneficiaries, applications, Aadhaar, passwords, OTP, documents containing private personal data, or CAPTCHA-protected content.
5. Run a manual single-record trial only after permitted access is established; record completeness and semantic correctness.
6. Mark approved paths explicitly; disallow all other paths by default.
7. For scheme rules, cite an active owning-department order; a directory or news release alone is not authoritative for all exceptions.
